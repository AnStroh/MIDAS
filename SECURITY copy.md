# Security Policy

We take security issues seriously. We appreciate all efforts to responsibly
disclose any security issues and will make every effort to acknowledge
contributions.

## Supported Versions

MIDAS is early-stage (pre-1.0) - only the latest release on `main` is
supported with fixes. See [CHANGELOG.md](CHANGELOG.md) for the version
history.

## Reporting a Vulnerability

Once this repository is public, please use GitHub's Security Advisory
["Report a Vulnerability"](../../security/advisories/new) tab on this repo.
Until then, email the maintainers directly at anstroh@uni-mainz.de.

We will send a response indicating the next steps in handling your report,
and keep you informed of progress toward a fix.

Please report security bugs in third-party dependencies (MATLAB, GNU
Octave, or any Octave Forge package) directly to their own maintainers.
